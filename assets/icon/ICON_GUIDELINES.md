# Pynelith 图标规范

> **当前 logo（beta0.1.8 起）**：玻璃胶囊主视觉，由 1024×1024 源图生成，四角 22.5% 圆角；
> ICO 含 16–256 多尺寸；深/浅两套 PNG 使用同一张全彩图。下方几何与配色规范对应旧版矢量图标，保留作历史参考。

> 版本 beta0.1.0 · 适用于 Windows 桌面端

## 1. 设计理念

图标由三件事构成，与产品一一对应：

| 图形元素 | 对应产品概念 |
| --- | --- |
| 圆角方形底板 | 悬浮在桌面之上的玻璃层 |
| 横置胶囊 | 灵动岛本体（屏幕顶部居中的胶囊形悬浮窗） |
| 胶囊内 5 条音频波形 | 媒体播放与实时歌词 |

在 512 px 基准下只有 3 层结构、5 个波形条，**没有任何装饰性细节**——这是为了 16 px 下仍然可辨识。

## 2. 几何比例（以 512 × 512 为基准）

| 元素 | 数值 | 比例说明 |
| --- | --- | --- |
| 画布 | 512 × 512 | — |
| 底板外边界 | x/y = 28，456 × 456 | 四边留白 5.5% |
| 底板圆角 | 102 | 边长的 22.5% |
| 胶囊 | 96.5, 198，319 × 116 | 宽 = 底板 70%，高 = 25.5% |
| 胶囊圆角 | 58 | 高度的一半（正胶囊） |
| 波形条宽 | 18 | 胶囊高的 15.5% |
| 波形条间距 | 18 | 与条宽等比 |
| 波形最大高度 | 62.6 | 胶囊高的 54% |

波形高度序列：`0.34 / 0.66 / 1.00 / 0.66 / 0.34`（中间最高，左右对称衰减）。

## 3. 配色（主色不超过 3 种）

### 深色模式（默认）

| 用途 | 色值 |
| --- | --- |
| 底板渐变 | `#1C2129` → `#07090C` |
| 胶囊填充 | `#232933` |
| 强调 / 波形 | `#7BE0FF`（Pynelith 强调青） |

### 浅色模式

| 用途 | 色值 |
| --- | --- |
| 底板渐变 | `#FFFFFF` → `#DBE7F8` |
| 胶囊填充 | `#F5F9FF` |
| 强调 / 波形 | `#2F6FED`（品牌蓝） |

两套模式共享同一几何，仅替换底色与强调色；透明度仅用于高光（白 22% / 55%）与描边（14% / 19%），不作为第四种主色计入。

**选择规则**：系统为深色主题 → 深色图标；浅色主题 → 浅色图标。任务栏、开始菜单、安装程序统一使用深色版（在浅色任务栏上仍具备足够对比度）。

## 4. 尺寸阶梯与使用场景

| 尺寸 | 场景 |
| --- | --- |
| 16 × 16 | 任务栏小图标、资源管理器列表、Alt+Tab 角标 |
| 24 × 24 | 小任务栏、通知区域 |
| 32 × 32 | 桌面快捷方式（小图标视图）、资源管理器 |
| 48 × 48 | 桌面快捷方式（中图标视图） |
| 64 × 64 | 大图标视图、安装程序标题栏 |
| 128 × 128 | 应用商店列表、控制面板卸载项 |
| 256 × 256 | 高 DPI 桌面、设置页图标 |
| 512 × 512 | 官网 / 宣传物料 / 商店详情页 |

**小尺寸适配策略**：≤ 32 px 时自动切换为「3 条波形 + 加粗条宽（0.30 / 0.62 比例）+ 更高胶囊（底板 34%）」，避免 5 条细线在像素网格上粘连。该规则已内置在 `pynelith.ico` 与各 PNG 中，无需手工处理。

## 5. 安全边距与安全区

- **外部安全边距**：底板四周留 5.5% 空白（512 基准下 28 px）。任何外部裁切、圆角遮罩都不得侵入该区域。
- **内容安全区**：胶囊距底板边缘 96.5 px（18.9%），波形距胶囊上下各 26.7 px。所有内容必须完整落在底板内，**不允许出血**。
- **最小可用尺寸**：16 px。低于此尺寸请使用纯色小方块或仅保留波形符号，不要继续缩放本图标。
- **圆角遮罩兼容**：若宿主强制套用圆角（如 Windows 11 开始菜单），请使用 `256 px` 及以上版本，并保持圆角半径不超过边长的 22.5%，否则底板边缘会出现双重圆角。

## 6. 禁用示例

| 禁止 | 原因 |
| --- | --- |
| 拉伸为非等比（如 512 × 256） | 胶囊变形，失去品牌识别 |
| 在底板内再叠加文字或版本号 | 小尺寸糊成一团 |
| 更换强调色（如改成红/绿） | 破坏「青/蓝 = 波形」的识别锚点 |
| 添加外部投影或发光 | 与 Windows 系统图标阴影叠加后显脏 |
| 旋转、倾斜、镜像 | 波形对称性被破坏 |
| 把波形改为 3 条以外的数量（≤32 除外） | 与规范不符 |

## 7. 交付文件

```
assets/icon/
├─ pynelith-dark.svg        矢量源（深色，512 视图）
├─ pynelith-light.svg       矢量源（浅色，512 视图）
├─ pynelith.ico             多尺寸 Windows 图标（16/24/32/48/64/128/256，深色）
├─ ICON_GUIDELINES.md       本文件
└─ png/
   ├─ pynelith-dark-{16,32,48,64,128,256,512}.png
   └─ pynelith-light-{16,32,48,64,128,256,512}.png
```

PNG 均为透明背景、直接按目标像素尺寸渲染（非缩放），因此边缘锐利。

## 8. 在项目中的使用

应用与安装包已通过 `<ApplicationIcon>` 引用 `pynelith.ico`：

- `Pynelith.Island.exe`（主程序）
- `beta0.1.0.exe`（安装程序，标题栏图标同为该文件）

在 XAML 中引用窗口图标：

```xml
<Window Icon="pack://application:,,,/pynelith.ico" ... />
```

制作宣传物料时请使用 `pynelith-dark-512.png` 或对应 SVG，不要从 `pynelith.ico` 直接放大（ICO 内最大帧为 256）。
